# URUS v0.1.0 — Foundation Reset

> The previous 0.2.x / 0.3.x line accumulated features faster than the foundation could absorb them. We renumbered to 0.1.0 to make it loud that **no public API or syntax is stable until 1.0**, and to commit to auditing every subsystem before any new feature lands. This is the first release on the new line.

Every language feature shipped in 0.2/0.3 is **still in the language**. What 0.1.0 adds is auditability, security hardening, and resilience.

---

## TL;DR

- **17 PRs** of foundation-hardening work landed across two stages.
- **2 silent miscompiles** surfaced and were fixed during the audit (latent `__xrealloc` write-back miss, tuple-of-tuple typedef pointer aliasing).
- **Build now refuses native MSVC** (`#error` + CMake guard) — RAII via `__attribute__((cleanup))` is a hard requirement; clang-cl / MSYS2 GCC / WSL still work.
- **AddressSanitizer + UndefinedBehaviorSanitizer** matrix in CI.
- **Codegen is byte-deterministic** — asserted by a CTest fixture so the next change that breaks reproducible builds fails in PR review.
- **Pipeline green again** after the CI repair PR (#204) — see "CI repair" below.

## What changed by subsystem

### Memory safety

- All compiler-internal allocations now funnel through `xmalloc` / `xcalloc` / `xstrdup` / `xrealloc` (abort-on-OOM, no NULL-deref). 53 call sites converted. ([#192](https://github.com/Urus-Foundation/Urus/pull/192))
- Fixed a latent `__xrealloc` bug that was returning the new pointer but never writing it back through the `void **` out-parameter. ([#192](https://github.com/Urus-Foundation/Urus/pull/192))
- Five hardcoded `MAX_*` caps removed; tables grow on demand via `xrealloc`-backed grow-by-2 scheme. ([#188](https://github.com/Urus-Foundation/Urus/pull/188))
- `tuple_type_name` returns a heap-owned string; the previous 512-byte static buffer caused a **silent miscompilation** on tuples-of-tuples where pointer aliasing across recursive emits clobbered the outer name. ([#193](https://github.com/Urus-Foundation/Urus/pull/193))

### Process and IO security

- Package manager `git clone` no longer goes through `system()`. URLs validated against a strict allowlist before being passed as `argv` to `fork`/`execvp` (POSIX) or `_spawnvp` (Windows). ([#186](https://github.com/Urus-Foundation/Urus/pull/186), [#187](https://github.com/Urus-Foundation/Urus/pull/187))
- Compiler driver no longer creates predictable `_urus_tmp_<pid>.c`. Now uses `mkstemps` (POSIX) / `_sopen_s` + `_O_CREAT|_O_EXCL` (Windows). Closes the TOCTOU symlink-substitution window. ([#194](https://github.com/Urus-Foundation/Urus/pull/194))
- WASM/`emcc` backend no longer runs through `system()`. Invoked via `argv`-style spawn. ([#194](https://github.com/Urus-Foundation/Urus/pull/194))
- Stdlib `http.urus` validator tightened to reject all bytes < 0x20, DEL, and the full bash metaset (was missing `'`, `<`, `>`, `(`, `)`, `*`, `?`, `[`, `]`, `{`, `}`, `!`, control chars). The real fix (argv exec of curl) is tracked in [ADR-004](./documentation/decisions/ADR-004-stdlib-audit-v0.1.0.md). ([#200](https://github.com/Urus-Foundation/Urus/pull/200))

### Resilience

- Preprocessor detects circular imports and prints a human-readable cycle path before aborting. ([#190](https://github.com/Urus-Foundation/Urus/pull/190))
- LSP `uri_to_path` rewritten with bounds-checked reads and propagated allocation failures — the previous version read one past the end of a truncated `file:///C` URI. ([#187](https://github.com/Urus-Foundation/Urus/pull/187))
- Parser panic-mode error recovery: a single syntax error no longer suppresses every following diagnostic in the same compile. ([#198](https://github.com/Urus-Foundation/Urus/pull/198))
- Sema scope lookup is now amortized O(1) via FNV-1a hash index (was O(n) per lookup). ([#191](https://github.com/Urus-Foundation/Urus/pull/191))

### Build and CI

- Native MSVC is refused at CMake configure time. URUS's RAII path depends on `__attribute__((cleanup))`, which MSVC silently no-ops; the build now fails with a clear message pointing at clang-cl / MSYS2 GCC / WSL. ([#199](https://github.com/Urus-Foundation/Urus/pull/199))
- Parallel-build race on the embedded-runtime generator (`urus_runtime.c`) fixed. The generator now runs exactly once through a CMake `OBJECT` library. ([#185](https://github.com/Urus-Foundation/Urus/pull/185))
- AddressSanitizer + UndefinedBehaviorSanitizer matrix job. ([#196](https://github.com/Urus-Foundation/Urus/pull/196))
- gcc + clang build matrix; `--version` smoke test; explicit determinism step. ([#204](https://github.com/Urus-Foundation/Urus/pull/204))
- Codegen byte-determinism regression test on six representative fixtures. ([#201](https://github.com/Urus-Foundation/Urus/pull/201))
- "Foundatation" typo in license header fixed across 13 files; the URL had been a dead link since project inception. ([#189](https://github.com/Urus-Foundation/Urus/pull/189))

### CI repair

The pipeline went red on PR #192 (Stage 2 start) and stayed red through #203 because every PR landed via admin-merge bypass (the maintainer's account is currently restricted; the alternative was halting the entire foundation pass). [PR #204](https://github.com/Urus-Foundation/Urus/pull/204) caught the workflow up to the code:

- `pkg.c` missing `#include "urusc.h"` — `xrealloc` is a macro, GNU ld emitted `undefined reference`.
- `mkstemps` invisible under `-std=c11` on glibc — needed `_DEFAULT_SOURCE` feature-test macro.
- `tests/determinism.cmake` was caught by the `*.cmake` glob in `.gitignore` and never tracked.
- `nested_tuple_typedef.urus` regression fixture had a syntactic bug (`pair.0.0` lexes as `pair . FLOAT`); rewritten to use intermediate bindings.
- LeakSanitizer was failing every `run_*` test because the compiler uses arena-style allocation and never frees the AST before `exit()`. `detect_leaks=0` set for now; tracked as a follow-up.

## Breaking changes

None at the source level — every program that compiled under 0.3.x still compiles under 0.1.0. The breaking changes are operational:

- **Native MSVC builds are rejected.** Switch to `clang-cl`, MSYS2 GCC, or WSL.
- **The version number went backwards.** If you have tooling that parses `urusc --version` and expects monotonic versions, update it.

---

## Known limitations carried into 0.1.x

- The compiler arena-allocates and exits without freeing — LeakSanitizer fires on every clean compile. Use the matrix with `detect_leaks=0` until a proper destroy() chain lands.
- `pair.0.0` syntax does not parse (lexer ambiguity with float literals); use intermediate bindings for nested tuple access.
- Pre-existing `-Wswitch` warnings on `TOK_ASYNC/AWAIT/TEST/TRY/CATCH/QUESTION` and `NODE_TRAIT_DECL/IMPL_BLOCK/...` — these are feature-stub enum values without runtime support yet.
- Stdlib `http_post` rejects `"` so JSON bodies don't work; argv-based `curl` exec is tracked in ADR-004.
